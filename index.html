One brief, with and without design skills

These are test pages, not real websites. Every page here was generated by an AI model from one brief, for a test written up on spoko.space: Do design skills fix AI-built pages? I tested four (Polish version). They are kept as they came out, defects included.

The same brief for the home page of a made-up housing cooperative, built in Claude Code by Sonnet 5.5, Opus 5.5 and Fable 5.2: once without a skill, then once with each of four design skills. The same brief then went to OpenAI's and Google's agents, to chat apps and to models running locally. One run per combination, so this shows tendencies, not a ranking.

The fifteen Claude Code runs were repeated once from scratch to see how much comes back the same. The qwen3 and Bielik runs without a skill and with frontend-design were repeated twice: they are at the end of the second trial and on a third page.

The brief (in Polish) · Method and versions · The repository

Tokens include cache reads, which are most of them. Detector counts the findings of Impeccable's own rule-based checker (npx impeccable detect), so it judges every page by one skill's rules. axe rules counts distinct WCAG 2.2 A/AA rules axe-core flags at 1440 and 390 px.
